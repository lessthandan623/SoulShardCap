# Changelog

## 1.2.0 (2026-11-16)
- Scans the extra bag slot (bag 5, shown as "Reagent Bag" in the modern UI). Soul bags such as the Box of Souls can sit there.
- Recognizes soul bags by name ("Soul", "Felcloth") as well as by the game's soul-bag flag.
- Debug log is saved to SavedVariables: `/ssc debug`, `/ssc debug off`, `/ssc debug clear`.

## 1.1.0 (2026-11-16)
- Diagnostic report (`/ssc debug`), and a chat warning if the game blocks an action.

## 1.0.0 (2026-11-15)
- First version: shard limit from soul bag size, extra shards deleted on your next key press, backup button, slash commands.
